# DIM-GT: Conformal Immune Prototype Memory with a Relational–Temporal Graph Transformer for Open-World Social Spam Detection

Reference implementation of every experiment in the manuscript. All files live in this single folder;
data, run outputs and figures are written to `data/`, `runs/` and `figs/` sub-folders that the scripts create.

## Requirements
Python 3.11+ and the packages in `requirements.txt` (CPU is sufficient; the paper used 2 vCPUs, 7 GB RAM).
`pandoc` is not required for the experiments.

## Data
* **YelpChi, Amazon** – `YelpChi.zip`, `Amazon.zip` from https://github.com/YingtongDou/CARE-GNN (`data/`); unzip the `.mat` files into `data/`.
* **Weibo, Reddit** – `weibo.pt.zip`, `reddit.pt.zip` from https://github.com/pygod-team/data; unzip the `.pt` files into `data/`.
  `ptload.py` reads them without PyTorch.
* **SpamSim-OW** – generated by `spamsim.py` / `sim_tokens.py` (platform presets A and B, seeds 0–4).

## Files
| File | Purpose |
|---|---|
| `ptload.py` | torch-free reader for PyG `.pt` files |
| `data_real.py`, `graphdata.py` | relation–hop tokens, splits, capped edge lists, hop tokens |
| `spamsim.py`, `sim_tokens.py` | open-world temporal social-spam simulator and relation–time tokens |
| `nets.py` | token transformer, immune prototype memory, losses, baselines (MLP, CNN, LSTM, GraphSAGE, R-GCN, RGT-style, BWGNN) |
| `train.py` | training loop, DIM-GT objective, conformal immune decision (`ImmuneConformal`) |
| `ais.py` | LR, RF, GBDT-Agg, NSA (V-detector) and NSA-GA |
| `metrics.py` | Macro-F1, PR-AUC, MCC, G-mean, ECE, Brier, AURC |
| `run_real.py` | closed-set comparison, ablations, robustness, sensitivity (Tables IV–VI, Figs. 5–7) |
| `run_open.py` | leave-one-mode-out open-set protocol (Table VII, Fig. 2) |
| `run_stream.py` | chronological open-world stream and its ablations (Tables VIII–IX, Figs. 3–4) |
| `run_xplat.py` | cross-platform transfer (Table X) |
| `bench.py` | warm-start inference latency |
| `analyze.py` | aggregation and statistics (Wilcoxon–Holm, Friedman) → `runs/results.json` |
| `fig_arch.py`, `fig_results.py`, `fig_embed_compute.py`, `fig_embed_plot.py` | figures |
| `run_all.sh` | end-to-end reproduction |
| `results.json` | aggregated results reported in the paper |

## Reproduce
```bash
pip install -r requirements.txt
bash run_all.sh          # several hours on 2 CPU cores
```
Single runs, e.g. `python run_real.py yelpchi dimgt 0,1,2,3,4` or `python run_stream.py "dimgt;er" 0,1,2`.

## Key settings
d=64, L=2 layers, 4 heads, d_e=32, M_s=6 self cells, M_n=3 non-self cells, γ=0.1, κ=10, λ_c=0.3, λ_n=1,
m_tol=0.75, m_cen=0.35, AdamW 2e-3, α=0.05, stream budget 150 labels/window, encoder updated at 0.1× rate.
